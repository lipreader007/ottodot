# Ottodot – AI Math Problem Generator (P5)

A full-stack demo using Next.js + TypeScript + Tailwind + Supabase with Gemini for problem generation and personalized feedback.

## Getting Started
1. Run `supabase/schema.sql` in Supabase SQL Editor.
2. `npm i` then `npm run dev`

## Deployment
- Public vars: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- Server vars: `GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY` (optional)
